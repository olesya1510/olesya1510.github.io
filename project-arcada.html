Аркада Опт

Коммерческий B2B-бот для Аркадо-Гранит, созданный для автоматизации работы менеджеров и приёма оптовых заказов в МАКС.

Python МАКС Polling B2B

Что это

Внутренний и клиентский бот для менеджеров компании и оптовых покупателей изделий из камня: гранита, мрамора и памятников.

Задача

Автоматизировать приём входящих заявок, предоставить каталог с удобной навигацией и провести пользователя через сквозной сценарий «оформить заказ» с фиксацией данных.

Что было сделано

  • разработана backend-логика проекта на Python
  • создан каталог оптовых товаров с inline-клавиатурами
  • реализован сценарий оформления заказа и сохранения данных
  • бот развёрнут на выделенном изолированном сервере с polling

Результат

Менеджеры и оптовые клиенты получают единый сценарий для работы с каталогом и заявками, а компания сокращает ручную обработку заказов. Я выступала единственным backend-разработчиком проекта.
